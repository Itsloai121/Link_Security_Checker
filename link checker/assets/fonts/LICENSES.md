# Font licences

All three fonts are self-hosted (no third-party requests at runtime) and distributed under the SIL Open Font License 1.1.

| Font | Used for | Source package |
|---|---|---|
| Unbounded (variable, latin subset) | Headings and verdict words | `@fontsource-variable/unbounded` 5.3.0 |
| Instrument Sans (variable, latin subset) | Body text | `@fontsource-variable/instrument-sans` 5.3.0 |
| JetBrains Mono (variable, latin subset) | URLs and technical evidence | `@fontsource-variable/jetbrains-mono` 5.3.0 |

The full licence text ships inside each npm package (`LICENSE`), copied next to the font files. Arabic and other scripts fall back to the system font stack.
